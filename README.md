# 🚀 Swag Labs Automation Framework

A UI test automation framework built with **Playwright** and **TypeScript** following industry best practices such as Page Object Model (POM), reusable test data, and scalable project structure.

---

## 🛠️ Tech Stack

* Playwright
* TypeScript
* Node.js
* Git
* GitHub

---

## 📁 Project Structure

```text
├── pages/       # Page Object Models
├── tests/       # Test cases
├── data/        # Test data
├── fixtures/    # Custom fixtures
├── utils/       # Utility functions
├── README.md
└── playwright.config.ts
```

---

## ▶️ Available Commands

### Run all tests

```bash
npm run test
```

### Run tests with visible browser

```bash
npm run headed
```

### Open Playwright UI Mode

```bash
npm run ui
```

### Open HTML Report

```bash
npm run report
```
